# Modern Portfolio Website

## Files
- index.html
- style.css
- script.js
- images/profile.jpg
- resume/resume.pdf

## Run in VS Code
1. Extract the ZIP.
2. Open the `portfolio-modern` folder in VS Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click -> Open with Live Server.
6. The website opens in your browser.

## Customize
- Replace `Your Name` in index.html.
- Replace the college and education details.
- Replace email/GitHub/LinkedIn links.
- Put your photo at `images/profile.jpg`.
- Put your PDF at `resume/resume.pdf`.
- Replace project links (`href="#"`) with your real project URLs.

## Important
The contact form is currently front-end only. It displays a confirmation message but does not send email. Connect a backend or form service when you want real submissions.
